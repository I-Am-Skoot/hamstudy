# hamstudy
United States Amateur radio test prep tool
These are the actual questions from the exam.

Usage:
$> python study.py

There are two modes, Study mode, and Test Mode.

Study mode will allow you to study individual Sub-elements, or Sections of the sub-elemets until you are confident.  
For each section any quetion you get wrong will be repeated until you answer all question in that section correctly. 

Test mode will randomly select 1 question from each section just like the real test.
